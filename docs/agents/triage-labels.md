# Triage labels

工程技能使用五个标准 triage 状态。本文件将这些状态映射到本仓库实际使用的状态字符串。

| 技能中的标准状态 | 本仓库使用的状态 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，代理可以直接处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不再处理 |

技能提及某个标准 triage 状态时，使用本表对应的本仓库状态字符串。
